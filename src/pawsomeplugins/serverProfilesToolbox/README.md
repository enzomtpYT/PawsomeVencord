# ServerProfilesToolbox

Manage, switch, copy, paste, and reset server profile overrides (nicknames, pronouns, bios, theme colors, banners, avatars, and profile effects) across any server with persistent DataStore presets and JSON import/export.

## Features

- **Persistent Presets**: Save your server identity (nickname, pronouns, bio, avatar, banner, colors, decorations) into named presets stored in DataStore.
- **Quick Copy / Quick Paste**: Instantly copy your current server identity and paste it into another server.
- **JSON Import / Export**: Share or back up your profile presets as JSON.
- **Reset Overrides**: Instantly revert server-specific overrides back to your default account profile.
- **Modern Discord Studio Compatibility**: Injects directly into Discord's modern profile studio sidebar (`UserProfileModalV2EditingPanel`).

## How to Access

You can open the **Server Profiles Toolbox** from anywhere in Discord:

1. **Toolbox Icon / Title Bar**: Click the Toolbox menu in the top bar -> **Server Profiles Toolbox**.
2. **Server Context Menu**: Right-click any server icon in the server list or server header -> **Server Profiles Toolbox** (opens directly pre-selected for that server).
3. **User Context Menu**: Right-click yourself in chat or a member list -> **Server Profiles Toolbox**.
4. **Plugin Settings**: Go to User Settings -> Plugins -> ServerProfilesToolbox -> click **Open Server Profiles Toolbox**.
5. **Profile Studio Editor**: In User Settings -> Profiles, click **Open Toolbox** in the sidebar.
